# รูปโปรเจกต์

วางไฟล์รูปของแต่ละโปรเจกต์ไว้ในโฟลเดอร์นี้ แล้วไปผูกกับข้อมูลใน
`src/lib/project-archive.ts`

## วิธีเพิ่มรูปหน้าปก

1. วางไฟล์ เช่น `coresync-cover.jpg` ไว้ในโฟลเดอร์นี้
2. เปิด `src/lib/project-archive.ts` หาโปรเจกต์ที่ต้องการ แล้วเพิ่ม

```ts
cover: {
  src: "/projects/coresync-cover.jpg",
  alt: "แดชบอร์ด CoreSync แสดงสถานะเครื่องจักรทั้ง 4 สาย",
},
```

`alt` คือคำอธิบายภาพสำหรับคนที่ใช้โปรแกรมอ่านหน้าจอ **ต้องใส่** — เขียนว่าในภาพมีอะไร
ไม่ใช่แค่ชื่อโปรเจกต์

**ถ้าไม่ใส่ `cover` เลยก็ได้** ระบบจะใช้พื้นไล่สีแทน และเลือกสีจากชื่อ slug
ทำให้กล่องเดิมได้สีเดิมทุกครั้ง ไม่ต้องรีบหารูป

## ถ้าของสำคัญไม่ได้อยู่กลางภาพ

การ์ดครอปเป็น 16:9 ส่วนแถวอันดับครอปเป็น 3:4 ถ้าครอปแล้วส่วนสำคัญหาย ให้ใส่ `focus`

```ts
cover: {
  src: "/projects/x-tier-cover.jpg",
  alt: "หน้ากระดานงานของ X-Tier",
  focus: "50% 20%",   // ค่าเดียวกับ CSS object-position
},
```

## แกลเลอรีเพิ่มเติม

ใส่ได้หลายรูป จะขึ้นเป็นกริดท้ายหน้าโปรเจกต์

```ts
gallery: [
  { src: "/projects/coresync-quality.jpg", alt: "หน้าจอคุณภาพแบบ SPC" },
  { src: "/projects/coresync-energy.jpg", alt: "หน้าจอติดตามพลังงาน" },
],
```

## ขนาดไฟล์ที่แนะนำ

- หน้าปก: กว้าง 1600px กำลังดี (Next.js ย่อให้เองตามขนาดที่แสดงจริง)
- ใช้ `.jpg` สำหรับภาพหน้าจอ ถ้าเป็นภาพมีพื้นโปร่งค่อยใช้ `.png`
- ไฟล์ไม่ควรเกิน 500KB ต่อรูป เพราะกลุ่มผู้อ่านหลายคนเปิดจากมือถือผ่านเน็ตมือถือ
