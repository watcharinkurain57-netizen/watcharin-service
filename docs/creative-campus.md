# Creative Campus portfolio

Creative Campus is the homepage at `/` in Portfolio mode. The former homepage is preserved in `src/components/home/LegacyHome.tsx`; the archive, authentication, internal workspace, actions, database code and migrations remain in the repository. The release is tracked in PR #49 and uses the existing GitHub/Vercel project and production domain.

## Start and review

```sh
pnpm install --frozen-lockfile
pnpm dev --hostname 127.0.0.1 --port 8767
pnpm build
```

Open `http://127.0.0.1:8767/` or `/campus/work`. The standard production build uses Next.js's supported Webpack path (`next build --webpack`); the local Turbopack build failed in its Google font import resolver. Development continues to use Turbopack.

The default Portfolio build uses reviewed local content. Supabase credentials are not required while the internal workspace is closed. There are no placeholder database credentials or fallback project records.

## Reversible feature switches

| Setting | Default | Result |
| --- | --- | --- |
| `SITE_MODE` | `portfolio` | Creative Campus at `/`; `/campus` temporarily redirects to `/` |
| `INTERNAL_WORKSPACE_ENABLED` | `false` | Close legacy archive/workspace, sign-in, invitations, actions and meeting reminder endpoint |
| `SITE_MODE=legacy` | Explicit opt-in | Restore the preserved former homepage; requires the workspace to be enabled |

To reopen internal features, set `INTERNAL_WORKSPACE_ENABLED=true`, configure the existing `NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`, then rebuild/redeploy. Keep `SITE_MODE=portfolio` to retain the new public homepage. To restore the former homepage too, set `SITE_MODE=legacy`. Invalid switch values and an enabled workspace without credentials fail during build/start. A build with internal features enabled still requires its live archive database.

With the workspace closed:

- `GET`/`HEAD /projects` temporarily redirect (307) to `/campus/work`; `/start` redirects to `/campus/contact`. Temporary redirects permit reopening the original paths later.
- Other `/projects/*`, `/clients`, `/requests`, `/login`, `/invite/*`, `/auth/*` and `/api/cron/meeting-reminders` requests return 404. Writes to `/projects` and `/start` are also closed.
- The proxy blocks legacy Server Action requests on public pages. Server page, data, action, auth-handler and cron-handler entry points check the switch too; file-like slugs that skip the proxy remain closed.
- Portfolio, public Studio/AI pages, the CoreSync demonstration and `/api/contact` remain independent of workspace sessions.

These switches control website availability. They do not remove database records, alter Supabase RLS or revoke database credentials. Reopening features preserves their existing authentication and authorization checks. Live sign-in and database writes have not been tested because credentials are absent.

## Contact and inquiries

Zone and project CTAs carry the work category into Contact. The visitor can change among four topics or choose a general inquiry. When delivery is unavailable, the email link contains the selected topic and a brief template for the project, goal and timing; opening it does not send anything.

The form requires both `RESEND_API_KEY` and a valid, explicitly configured `RESEND_FROM`; the destination defaults to `watcharin@watcharin-service.com` and can be overridden with `CONTACT_TO_EMAIL`. Rebuild when changing these settings because the Contact page is static. Sender-domain verification and permissions must still be checked in Resend.

Submitting retains input on failure and offers direct email. A 20-second client timeout stops an indefinite wait; retries of identical input reuse the provider idempotency key. Error/success panels receive focus and announce their status. The form reports success only after the provider returns an acceptance ID, without promising a 24-hour response or claiming inbox delivery. Invalid/non-object payloads and unknown topics return 400; unavailable delivery returns 503; provider failures/empty acceptance return 502. Responses are not cached and provider details/contact contents are not logged.

Studio's remaining current-live and response-time claims were aligned with the reviewed content; its education dates now match the Resume.

## Motion and accessibility

`CampusShell` owns image transitions, scroll restoration, return context, focus and section reveals. Cards expand into a project cover in 560 ms; section reveals use 520 ms and a small stagger. Browser Back restores the reading position, and return links keep the project's source zone or category.

The Home scene dynamically imports the installed Three.js package. It retains the approved campus geometry, intro, camera journeys and car controls. Leaving Home cancels animation work, disconnects observers, removes listeners and disposes geometry, materials, textures and the renderer. Rendering stops while idle, hidden or offscreen.

The OS reduced-motion preference and the user's “ลด Motion” toggle disable decorative journeys, image flights and reveals while preserving navigation and reading position. `/?scene=poster` exercises the static fallback. Native zone links remain accessible without the scene.
